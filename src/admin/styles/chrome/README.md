# Chrome icons

SVG assets under `icon/`:

- SCSS under this folder is **owned Retro OS chrome** (not the npm `98.css` package).
- Many control glyphs historically come from [98.css](https://github.com/jdan/98.css) (MIT License); attribution retained for that lineage.
- `button-*-disabled.svg` are WebHemi additions for the custom product scrollbar (disabled arrow buttons); kept here so all chrome control glyphs live in one place.
